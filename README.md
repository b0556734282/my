# אתר עמותת מרכז התורה והחסד

אתר תדמית ותרומות לעמותה — עברית מלאה (RTL), מותאם לנייד, ללא צורך בשרת.

בנוי מ-HTML, CSS ו-JavaScript בלבד: אין התקנות, אין בנייה, אין תלויות.
פותחים את `index.html` בדפדפן וזהו.

> **חשוב:** האתר הזה שייך ל**עמותת מרכז התורה והחסד** בלבד.
> חיידר תורת שלום הוא גוף נפרד לגמרי, ואין להזכיר אותו כאן. ראו `CLAUDE.md`.

---

## מה צריך לעשות כדי לעלות לאוויר

**כל הפרטים של העמותה נמצאים בקובץ אחד: `assets/js/config.js`.**
זה הקובץ היחיד שצריך לערוך. מה שממלאים שם מופיע אוטומטית בכל עמודי האתר,
ומה שנשאר ריק פשוט לא מוצג — בלי שום שגיאה ובלי שדות ריקים מכוערים.

### רשימת המילוי

| שדה ב-`config.js` | מה למלא | בלי זה |
|---|---|---|
| `amutaNumber` | מספר העמותה הרשום | לא מוצג מספר עמותה |
| `phone` | טלפון המשרד | שורת הטלפון נעלמת |
| `whatsapp` | מספר לוואטסאפ | הקישור לוואטסאפ נעלם |
| `email` | כתובת מייל לפניות | שורת המייל נעלמת |
| `nedarim.mosadId` + `nedarim.apiValid` | הפרטים מנדרים פלוס | דף התרומה מפנה להעברה בנקאית / ביט |
| `bank.*` | פרטי חשבון הבנק | פרטי ההעברה לא מוצגים |
| `bit` | מספר לביט / פייבוקס | שורת הביט נעלמת |
| `formEndpoint` | כתובת Formspree (לא חובה) | הטופס נשלח בוואטסאפ או במייל |
| `siteUrl` | כתובת האתר המלאה | אין קישור קנוני ואין כתובת בשיתוף |

### הגדרות נוספות

| שדה | מה זה עושה |
|---|---|
| `donation.min` / `donation.max` | הסכום המינימלי והמקסימלי לתרומה. גם מגן מקישורים עם סכום חריג |
| `donation.presets` | הסכומים המוכנים בתרומה חד־פעמית |
| `donation.presetsMonthly` | הסכומים המוכנים בהוראת קבע |
| `donation.hourCost` | עלות שעת לימוד — לחישוב "התרומה הזו מממנת X שעות לימוד" |
| `campaign.goal` / `campaign.raised` | פס התקדמות של קמפיין בעמוד הבית. `goal: 0` = הפס לא מוצג |
| `campaign.deadline` | תאריך סיום (`"2026-12-31"`) — מציג ספירת ימים |
| `showHebrewDate` | תאריך עברי בכותרת העליונה |
| `allowDarkMode` | כפתור מעבר למצב לילה |

בנוסף, כדאי לעדכן:

- **המספרים במקטע "העמותה במספרים"** — ב-`index.html`, במאפיין `data-count`.
- **השאלות והתשובות** — ב-`index.html`, במקטע `#faq`.
- **תמונות** — לפי ההוראות ב-`assets/img/README.md`.

.well-known/security.txt     ← לדיווח על בעיות אבטחה
SECURITY.md                  ← ★ תיעוד ההגנות — לקרוא לפני שינויים

sitemap.xml / robots.txt     ← לגוגל

## מה יש באתר

### עמוד הבית
- כותרת ראשית עם שלושה סימני אמון (קבלה לצורכי מס, סליקה מאובטחת, שקיפות).
- מקטע אודות, חמש מסגרות הפעילות, נתונים במספרים עם ספירה מונפשת.
- **פס התקדמות קמפיין** — נדלק לבד כשממלאים `campaign.goal` ב-`config.js`.
- שלושה מסלולי תרומה, גלריה עם **הגדלת תמונה** וניווט במקלדת.
- **שאלות ותשובות** באקורדיון.
- טופס יצירת קשר עם בדיקות תקינות בעברית והגנה מפני ספאם.

### לאורך כל האתר
- **מצב לילה** — לפי הגדרת מערכת ההפעלה, או בבחירה ידנית שנשמרת בדפדפן.
- **תאריך עברי** בכותרת (מחושב בדפדפן, בלי שום שירות חיצוני).
- פס התקדמות גלילה, הדגשת המקטע הנוכחי בתפריט, כפתור חזרה למעלה.
- כפתורי שיתוף בוואטסאפ והעתקת קישור.
- אפשר להתקין את האתר כאפליקציה בנייד (`manifest.webmanifest`).

## דף התרומה

`donate.html` תומך ב:

- **תרומה חד־פעמית** או **הוראת קבע חודשית** (12 / 24 / 36 חודשים או עד להודעה חדשה).
- סכומים מוכנים מתוך `config.js`, או כל סכום אחר.
- שורת "**התרומה הזו מממנת X שעות לימוד**" שמתעדכנת בזמן אמת.
- שדה **הקדשה** (לעילוי נשמת / לרפואת), שנשלח יחד עם התרומה.
- העתקת פרטי חשבון הבנק בלחיצה אחת.
- הגעה עם סכום מוכן מראש מעמוד הבית: `donate.html?amount=180&type=monthly`.

### חיבור נדרים פלוס

ממלאים ב-`config.js`:

```js
nedarim: {
  mosadId:  "1234",
  apiValid: "המחרוזת שקיבלתם מנדרים פלוס"
}
```

- **שניהם מלאים** → מסך הסליקה נפתח בתוך העמוד, ובסיום מוצלח הגולש מועבר ל-`thanks.html`.
- **רק `mosadId`** → מעבר לעמוד התרומה המאובטח של נדרים פלוס, עם הסכום שנבחר. עובד מיד.
- **שניהם ריקים** → הכפתור מפנה בעדינות להעברה בנקאית / ביט / טלפון, בלי שום שגיאה.

## טופס יצירת הקשר

הטופס בודק תקינות בעברית, ואז שולח לפי מה שמוגדר ב-`config.js`, בסדר הזה:

1. **`formEndpoint`** מלא → הפנייה נשלחת ישירות לשרת (Formspree וכדומה). **זו האפשרות המומלצת.**
2. אחרת, **`whatsapp`** מלא → נפתח וואטסאפ עם הפנייה מוכנה.
3. אחרת, **`email`** מלא → נפתחת תוכנת המייל של הגולש.

### חיבור Formspree (חינם עד 50 פניות בחודש)

1. נרשמים ב-[Formspree](https://formspree.io) ויוצרים טופס חדש.
2. מעתיקים את הכתובת שמתקבלת אל `formEndpoint` בקובץ `config.js`.

שירות טפסים **אחר** ידרוש גם עדכון של `connect-src` במטא־תג ה-CSP שבכל עמוד,
אחרת הדפדפן יחסום את השליחה. ראו `SECURITY.md`.

## אבטחה ופרטיות

התיעוד המלא נמצא ב-**[`SECURITY.md`](SECURITY.md)**. בקצרה:

- מדיניות תוכן (CSP) נוקשה בכל עמוד — אין סקריפטים חיצוניים, אין `unsafe-inline`.
- הגנה מפני הטמעת האתר בתוך אתר זר (Clickjacking).
- אימות מקור להודעות מול מסגרת הסליקה — אי אפשר לזייף "התרומה בוצעה".
- הגבלת סכום התרומה, גם כשהוא מגיע מכתובת URL.
- הגנת ספאם בטופס: שדה מלכודת, מדידת זמן והגבלת קצב.
- **אין** Google Analytics, אין עוגיות מעקב ואין פרסומות. הגופנים מאוחסנים באתר עצמו.

⚠ לפני שמוסיפים סקריפט, גופן או שירות חיצוני כלשהו — לקרוא את `SECURITY.md`.
בלי עדכון ה-CSP, הדפדפן פשוט יחסום אותו והתוספת "לא תעבוד" בלי הסבר.

## שינוי צבעי המותג

בראש `assets/css/style.css`, בבלוק `:root`:

```css
--brand: #12325a;   /* הצבע הראשי */
--gold:  #c8a24a;   /* צבע ההדגשה */
```

צבעי מצב הלילה נמצאים מתחת, בבלוקים `@media (prefers-color-scheme: dark)`
ו-`:root[data-theme="dark"]` — יש לעדכן את שניהם.

## העלאה לאוויר (GitHub Pages — בחינם)

1. בגיטהאב: **Settings → Pages**.
2. תחת **Build and deployment → Source** בוחרים **GitHub Actions**.
3. כל דחיפה ל-`main` מפרסמת את האתר אוטומטית, בכתובת:
   `https://<שם-המשתמש>.github.io/<שם-הריפו>/`

> **`main` הוא מקור האמת.** עבודה שנשארה בענף צדדי ולא מוזגה ל-`main` לא תעלה לאוויר.

לחיבור דומיין פרטי (למשל `toratshalom.org.il`): באותו מסך, תחת **Custom domain**,
ואצל רשם הדומיינים מפנים רשומת CNAME לכתובת שגיטהאב נותן.
אחרי חיבור הדומיין יש לעדכן את `siteUrl` ב-`config.js`, וגם את `robots.txt` ו-`sitemap.xml`.

## תצוגה מקומית

```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

חשוב לגלוש דרך `http://localhost` ולא לפתוח את הקובץ ישירות (`file://`) —
חלק מההגנות והכלים של הדפדפן לא עובדים בפתיחה ישירה.

## נגישות ותאימות

- ניווט מלא במקלדת, קישור "דילוג לתוכן", מלכודת פוקוס בתפריט הנייד, וסימון פוקוס ברור.
- הגלריה המוגדלת נסגרת ב-Esc ומתנווטת בחצים.
- כיבוד העדפת המערכת להפחתת אנימציות (`prefers-reduced-motion`) ולמצב כהה.
- עיצוב רספונסיבי מ-320px ומעלה, וגיליון עיצוב נפרד להדפסה.
- נתוני NGO מובנים לגוגל (JSON-LD) נבנים אוטומטית מתוך `config.js`.
