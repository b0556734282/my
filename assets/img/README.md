# תמונות האתר

לכאן מעלים את התמונות של העמותה. שמות הקבצים שהאתר מצפה להם:

| קובץ | לשימוש | גודל מומלץ |
|------|---------|-------------|
| `favicon.svg` | האייקון הקטן בלשונית הדפדפן | 64×64 |
| `og-image.jpg` | התמונה שמופיעה בשיתוף בוואטסאפ וברשתות | 1200×630 |
| תמונות גלריה | מקטע הגלריה בדף הבית | 1200×900 |

## איך מחליפים תמונת גלריה

בקובץ `index.html`, במקטע הגלריה, מחליפים את שורת ה-placeholder:

```html
<figure><div class="ph">📷</div><figcaption>סדר לימוד בכולל</figcaption></figure>
```

בתמונה אמיתית:

```html
<figure>
  <img src="assets/img/kollel.jpg" alt="אברכים לומדים בבית המדרש" loading="lazy">
  <figcaption>סדר לימוד בכולל</figcaption>
</figure>
```
