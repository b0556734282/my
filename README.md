# אתר עמותת תורת שלום

אתר תדמית ותרומות לעמותה — עברית מלאה (RTL), מותאם לנייד, ללא צורך בשרת.

בנוי מ-HTML, CSS ו-JavaScript בלבד: אין התקנות, אין בנייה, אין תלויות.
פותחים את `index.html` בדפדפן וזהו.

---

## מבנה הקבצים

```
index.html                  ← כל תוכן האתר נמצא כאן
assets/css/style.css        ← עיצוב (צבעים, גופנים, פריסה)
assets/js/main.js           ← תפריט נייד, אנימציות, טופס יצירת קשר
assets/img/                 ← תמונות (ראו README בתוך התיקייה)
.github/workflows/deploy.yml ← פרסום אוטומטי ל-GitHub Pages
```

---

## מה חשוב לעדכן לפני שעולים לאוויר

כל המקומות שדורשים עריכה מסומנים בקובץ `index.html` בהערה
`<!-- ========= לעריכה: ... ========= -->`. אלו הם:

1. **שם העמותה ומספר העמותה** — בכותרת הדף, בתפריט העליון ובפוטר.
2. **פרטי קשר** — טלפון, מייל, כתובת וקישור הוואטסאפ (במקטע "צור קשר").
3. **פרטי תרומה** — חשבון בנק, ביט/פייבוקס וסעיף 46 (במקטע "להיות שותף").
4. **המספרים במקטע "העמותה במספרים"** — דרך המאפיין `data-count`.
5. **תמונות** — לפי ההוראות בקובץ `assets/img/README.md`.
6. **כתובת המייל בטופס** — המשתנה `TO_EMAIL` בקובץ `assets/js/main.js`.

### שינוי צבעי המותג

בראש הקובץ `assets/css/style.css`, בבלוק `:root`:

```css
--navy: #12325a;   /* הצבע הראשי */
--gold: #c8a24a;   /* צבע ההדגשה */
```

## טופס יצירת הקשר

כרגע הטופס בודק את התקינות של השדות ואז פותח את תוכנת המייל של הגולש —
עובד בלי שרת, אבל דורש מהגולש ללחוץ "שלח" גם בתוכנת המייל שלו.

**לקבלת הפניות ישירות למייל** (מומלץ, וחינם עד 50 פניות בחודש):

1. נרשמים ב-[Formspree](https://formspree.io) ויוצרים טופס חדש.
2. מעתיקים את הכתובת שמתקבלת.
3. ב-`index.html` מחליפים את השורה:

   ```html
   <form class="contact-form" id="contactForm" novalidate>
   ```

   בשורה:

   ```html
   <form class="contact-form" id="contactForm" action="https://formspree.io/f/הקוד-שלכם" method="POST">
   ```

הקוד ב-`main.js` מזהה לבד שיש `action` ולא מתערב בשליחה.

## העלאה לאוויר (GitHub Pages — בחינם)

1. בגיטהאב: **Settings → Pages**.
2. תחת **Build and deployment → Source** בוחרים **GitHub Actions**.
3. כל דחיפה לענף מפרסמת את האתר אוטומטית, בכתובת:
   `https://<שם-המשתמש>.github.io/<שם-הריפו>/`

לחיבור דומיין פרטי (למשל `toratshalom.org.il`): באותו מסך, תחת
**Custom domain**, ואצל רשם הדומיינים מפנים רשומת CNAME לכתובת שגיטהאב נותן.

## תצוגה מקומית

פשוט לפתוח את `index.html` בדפדפן. לחלופין, שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## נגישות ותאימות

- ניווט מלא במקלדת, קישור "דילוג לתוכן", וסימון פוקוס ברור.
- כיבוד העדפת המערכת להפחתת אנימציות (`prefers-reduced-motion`).
- עיצוב רספונסיבי מ-320px ומעלה, וגיליון עיצוב נפרד להדפסה.
